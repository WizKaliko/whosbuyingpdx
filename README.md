# Who's Buying PDX?

A private citizen project showing where the donors to Portland's business-backed city and county candidates also give.

- Site: plain static HTML (`index.html`, `profiles/`, `img/`), no build step.
- Data: Oregon ORESTAR campaign finance records, as of Oct 17, 2026. Individual donors only; amounts rounded; no donor names published.
- Sources are linked on every page.

Paid for by Kaliko Castille. Not authorized by any candidate or committee.
