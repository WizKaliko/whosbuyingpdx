# Who's Buying PDX?

A private citizen project showing where the donors to Portland's business-backed city and county candidates also give.

- Site: plain static HTML (`index.html`, `profiles/`, `img/`), no build step.
- Data: Oregon ORESTAR campaign finance records, as of Oct 17–18, 2026. Individual donors only; amounts rounded; no donor names published.
- Sources are linked on every page.

An independent citizen project. Not paid for or authorized by any candidate, campaign or committee. Built for under $20.
